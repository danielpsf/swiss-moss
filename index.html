Swiss Moss

Paper, ink and one green.

A small, opinionated design system for calm interfaces: a token set, a CSS component library, and a few dependency-free behaviours. Light and dark from the same tokens. No build step.

One sentence first

Every screen opens with a headline that states the situation in plain words. Counts live inside sentences, never as big numbers with tiny labels.

Lines, not boxes

Hairlines separate content. Cards are for things that float or take input: a command bar, a reply box, a dialog, a toast.

Nothing moves until you do

Motion answers an action and nothing else. Reduced-motion preferences are respected everywhere.

Install

Copy tokens/, css/ and js/ into your project, or point at them from this repository. Load Inter and Inter Tight from Google Fonts (both are open fonts), then:

<link rel="stylesheet" href="css/swiss-moss.css">
<script src="js/swiss-moss.js" defer></script>

Every class is prefixed with sm-. Every colour, size and radius is a custom property prefixed --sm-, so your own CSS can use them too. Dark mode follows the system by default; add data-theme="dark" or "light" on <html> to force one, or use the buttons above, which persist the choice.

Tokens

Switch the theme above to see the second set. Both live in tokens/tokens.css, and tokens/tokens.json holds the same values for tooling. line is the hairline for dividers and cards; control-line is the stronger border for inputs, selects, checkboxes, switch tracks and range tracks, at 3:1 against the page so a control is visible without its fill. npm run check verifies every text and control pair in both themes.

Menu button, keyboard and right-to-left

      
The menu button follows the ARIA menu-button pattern. Down or Up arrow on the button opens the list on the first or last item, or on the checked one. Arrow keys, Home and End move, a letter jumps to the next item that starts with it, Escape closes and returns focus to the button, and a click or Tab outside closes it. Items are buttons with role="menuitem" or role="menuitemradio" (with aria-checked). Choosing one fires an sm:select event on the menu with { item, value }. The list lines up with the start edge of the button, or with its end edge when you add the end modifier (use it for a menu near the end edge of the page), and it mirrors with dir="rtl". Add menus after page load with SwissMoss.init(root).
